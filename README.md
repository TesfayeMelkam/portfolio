# Tesfaye Melkam — Portfolio

Responsive multi-page portfolio built with HTML, CSS, and JavaScript.

## Pages
- `index.html` — Home and portrait
- `about.html` — Biography, education, research interests
- `skills.html` — Python, Java, Kotlin, Prolog, Go and technical learning areas
- `projects.html` — Project cards with category filters
- `contact.html` — Email, GitHub, LinkedIn, and a mailto contact form

## Run locally
Extract the ZIP and open `index.html`, or run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Before publishing
Verify project URLs, keep skill descriptions accurate, add a Student Performance Prediction repository when available, and only add demos/results that genuinely exist. The contact form opens an email app; it does not send messages to a backend. The portrait image is the one supplied by the portfolio owner.
